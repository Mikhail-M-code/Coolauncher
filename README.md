# Coolauncher
Minecraft console launcher v0.1

# Releases
Download launcher > [Releases](https://github.com/Mikhail-M-code/Coolauncher/releases/tag/v0.1)

# System Requirements
OS Windows 7 SP1 / 8 / 10 / 11 (64-bit)

To run Minecraft you need to download Java 8 or higher!

[Download Java 8](https://www.java.com/ru/download/manual.jsp)
[Download Java 8 adoptium](https://github.com/adoptium/temurin8-binaries/releases/tag/jdk8u492-b09)

# Description

The launcher is based on the Python library minecraft_launcher_lib
